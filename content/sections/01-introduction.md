Generalist robotics policy. VLAs.

Language- and vision-language-based models show strong task planning capabilities in robotics. Code-as-policies (CaP) uses LLMs to synthesize executable code to control robots.

OpenAI released GPT-6 Astra, the first VLM shown by the community that is able to directly control robots, by outputting actions either in end-effector space or joint space. We refer this as Astra-as-policies (AaP).

We evaluate Astra-as-policies on real household mobile-manipulation tasks, in a real household environment.
